VGG16 Transfer Learning

Deep Convolutional Neural Network for image classification.

The current implementation of RenalScan AI utilizes a customized VGG16 architecture. Transfer learning was employed by utilizing pre-trained ImageNet weights, which allows the model to leverage robust, generalized feature extraction capabilities (edges, textures, shapes) before fine-tuning the dense layers specifically for kidney CT scans.

CT Image ↓ 224 × 224 preprocessing ↓ VGG16 (Base Layers) ↓ Feature extraction ↓ Flatten / Dense layer ↓ Softmax Activation ↓ 4 Target Classes

Target Classes

  • Cyst
  • Normal
  • Stone
  • Tumor

MLOps Infrastructure

1
DVC (Data Version Control): Used to pipeline the training workflow (ingestion, preprocessing, training, evaluation) and version the large underlying datasets and model binaries (`model.h5`).
2
MLflow: Tracks experiment runs, hyperparameters (epochs, learning rate), and resulting metrics (loss, accuracy) to ensure reproducibility.
3
DagsHub: Provides the remote remote storage backend for the DVC pipeline and hosts the MLflow tracking server.

Model Status: The currently deployed `model.h5` is utilized strictly for UI/UX and integration testing. Clinical accuracy metrics are intentionally withheld pending a final retraining phase resolving data-leakage and pipeline stabilization. This prototype is not clinically validated.
