Technical specifications of the RenalScan AI classifier.

Deep Convolutional Neural Network

Analysis Pipeline

1

Input Processing: The kidney CT image is loaded, converted to RGB, and resized exactly to 224 × 224 pixels.

2

Normalization: Pixel values are rescaled (1/255) to standardize the tensor distribution.

3

Feature Extraction: The image passes through the VGG16 base model (pre-trained weights), which applies successive convolutional blocks to extract hierarchical visual features.

4

Custom Classification: Features are flattened and passed through dense layers tailored specifically for this dataset.

5

Softmax Output: The final layer maps the probabilities across 4 categorical outcomes.

About RenalScan AI

What is RenalScan AI?
RenalScan AI is an AI-assisted kidney image classification application. It was developed as a deep-learning project to explore the capabilities of transfer learning (specifically the VGG16 network) in analyzing medical topography from Computed Tomography (CT) scans.

The application provides a modern, fast, and responsive dashboard interface to interact securely with the underlying Python/TensorFlow backend inference engine.

Medical Disclaimer

This application, its underlying machine learning model, and its predictions are intended strictly for educational and research purposes only.

RenalScan AI does not provide medical diagnoses, nor does it replace professional medical evaluation, imagery review, or clinical judgment. Never make health or treatment decisions based on the output of this application.
